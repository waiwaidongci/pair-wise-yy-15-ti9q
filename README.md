# hxyfront-62014 赛鸽训放记录

面向赛鸽棚的训放记录前端工具：以**训放批次**为核心登记放飞与归巢，自动计算用时、分速与排行。

## 功能与规则

- **训放批次**：每批登记放飞日期、时刻、地点、距离、天气和实际放飞名单。
- **归巢报时**：按足环登记归巢日期、时刻与健康状态；归巢日期独立于放飞日期。
- **跨夜计时**：次日凌晨归巢按真实日期先后计算用时，不会再被误判为"归巢早于放飞"。
- **有效成绩**：同羽同批只保留真实归巢时刻最早的一条（先到记录），重复报时自动沿用先到记录、不占排行。
- **待核**：批次缺距离、缺天气，或健康异常、时刻无效（含归巢早于放飞）的成绩只进待核，不占排行；补正后自动上榜。
- **未归巢名单**：已放飞但没有效归巢成绩的赛鸽自动列入；补录归巢后自动移出。时刻报成"早于放飞"的记录不能确认归巢，该羽继续留在名单。
- **自动重算**：任何成绩/批次更正后，本批排行、全棚总排行、鸽棚总览、单羽档案与血统历史全部由纯函数重新计算。
- **鸽棚档案**：足环、血统、性别、配对；按血统筛选历史成绩。
- **存档**：localStorage 自动保存，支持 JSON 导出/导入与恢复演示数据。

## 分层结构（规则 / 存档 / 页面分开）

```
src/
├── domain/            # 规则层：纯函数，不依赖 React 与存储
│   ├── types.ts       #   数据模型
│   ├── time.ts        #   跨夜计时、用时、分速
│   └── rules.ts       #   有效成绩、待核、排行、总览、血统档案
├── data/              # 存档层
│   ├── storage.ts     #   localStorage 读写、JSON 导入导出
│   └── seed.ts        #   演示数据
├── store.ts           # 状态：连接存档与规则，任何变更触发重算
├── ui/                # 通用组件与表单
├── pages/             # 页面：总览 / 批次 / 排行 / 待核 / 未归巢 / 档案
└── App.tsx
tests/smoke.ts         # 规则层断言（跨夜、重复报时、待核、未归巢、补录移出）
```

## 本地运行

```bash
npm install
npm run dev        # 开发端口 62014
npm test           # 规则层冒烟测试
npm run build      # 类型检查 + 生产构建
```

## 技术栈

React + Vite + TypeScript，无额外 UI/状态库；数据存于浏览器本地。
